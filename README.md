# Two-Way Factorial Analysis of Variance (ANOVA) with Interactions

## 📌 Project Overview 📌 
This project contains a comprehensive evaluation of factorial experimental designs using a Two-Way Analysis of Variance (ANOVA) model in R. Utilizing the standardized `warpbreaks` baseline distribution, the analysis investigates how multiple categorical factors (wool type and tension level) simultaneously influence a continuous metric, with an emphasis on detecting structural interaction variables.

## 📊 Statistical Concepts & Methods 📊
* **Two-Way Factorial Modeling:** Estimated simultaneous categorical group relationships including isolated main effects and crossed interaction cross-products (`wool * tension`).
* **Visual Assumption Diagnostics:** Utilized statistical plots to verify error distributions across normal quantiles and validate homoscedasticity constraints.
* **Interaction Matrix Plotting:** Programmed multi-variable interaction charts to trace cross-over effects between fiber structures and mechanical strain levels.
* **Tukey HSD Isolation Tests:** Applied post-hoc group variations to evaluate structural performance steps strictly between tension intervals.

## 📁 Repository Structure 📁 
* `twoway_anova_analysis.R`: The complete production script documenting model generation, mathematical diagnostic plots, interaction arrays, and post-hoc models.
